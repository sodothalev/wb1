# Mequbal Bilingual Glossary

This glossary is the working baseline for the bilingual web edition. Update it before adding each new chapter, then normalize the Spanish source and apply the English transliteration rules during translation.

## Rules

- Use `Qabalah` for the tradition in both English and Spanish web text.
- Use `qabalistic` in English and `qabalístico` in Spanish.
- Keep `HaShem`, `Ein Sof`, `Sefirot`, `Ohr`, `Keli`, `Tikun`, `devekut`, `avodat HaShem`, and `mequbal` as technical terms.
- Use Spanish accents for ordinary Spanish words such as `Torá`, but do not add accents to transliterated technical terms unless listed below.
- Keep one spelling per term inside each language. Do not alternate source variants such as `Tikún` and `Tikun`, `midot` and `middot`, or `halajá` and `halakhah`.
- The navigation hierarchy follows the user-approved main chapters: `Qabalah`, `Ein Sof`, `Partzufim`, `Arba Olamot`, `Ets Haim`, `Neshamot`, `Shemot HaKodesh`, `Derej HaAvodah`, `Tikun HaNefesh`, and `Epilogue`.

## Review Notes

- The web edition has been normalized to `Qabalah` in both languages.
- The Spanish source uses Spanish-style forms such as `Jojmá`, `Jesed`, `Maljut`, `Arij`, and `Yejidá`. The Spanish web text now uses `Jokhmah`, `Chesed`, `Malkhut`, `Arij`, and `Yechidah`; English uses `Chokhmah`, `Chesed`, `Malkhut`, `Arikh`, and `Yechidah`.
- The source heading `Ein Sof  אין אור` appears to show Hebrew text that reads like `Ohr Ein` rather than `Ein Sof`. The chapter heading should remain `Ein Sof` unless the source PDF is corrected.
- In the `Shem HaMeforash` chapter, PDF extraction reverses several Hebrew RTL sequences. The web text normalizes the `Ana Bekoach` groups, the prayer text, Shemot 14:19-21, and Zechariah 14:9 into readable Hebrew order instead of preserving the corrupted extraction order.
- In `Olam haAtzilut`, the source section `Netzach de Atzilut: Havayah Tzevaot` begins with duplicated `Tiferet` prose in the extracted PDF. The web text currently stops at `Tiferet de Atzilut` until that passage can be verified.
- In `Partzufim`, the PDF page headed `Ima` contains prose that repeats the `Aba/Abba` material. The web edition preserves that page as `Ima` with normalized terminology rather than inventing missing source text.
- In `Netivot`, PDF extraction attaches or reverses several Hebrew letter sequences. The web text normalizes `otiyot yesod`, `netivot chokhmah`, the three mother letters, the seven double letters, and the twelve simple letters into readable order.
- In `Daat`, PDF extraction attaches or reverses the Hebrew phrase for `sha'arei Binah`; the web text uses the transliterated phrase instead of preserving the corrupted extraction.
